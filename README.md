# 🎓 Student Chatbot Assistant

Because keeping track of assignments, deadlines, and university life is already hard enough. 

An AI-powered student assistant chatbot that helps students stay organized, answer questions, and keep an eye on their academic tasks.

## ✨ Features

- 💬 AI-powered conversations using Groq LLM
- 📋 Google Classroom integration
- 📝 Live assignment and pending-task tracking
- ⏰ Deadline and overdue-task detection
- 🧠 Persistent conversational memory
- 💾 Saved conversation history
- 🔄 Fetches fresh Classroom information when needed
- 🖥️ Streamlit interface

## 🛠️ Tech Stack

- 🐍 Python
- 🎈 Streamlit
- ⚡ Groq API
- 🎓 Google Classroom API
- 🔐 Google OAuth
- 💾 JSON storage
